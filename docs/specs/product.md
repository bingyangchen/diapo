## 定位

diapo 是一套純靜態網頁的簡報播放器與簡報框架。簡報的原始檔是程式碼，製作與播放都只需要瀏覽器，不依賴 Keynote、PowerPoint 這類專用 app，也不需要訂閱任何線上服務。同一份簡報建置出來的檔案可以在三種場地播放：

- 場地有網路時，開啟部署在 GitHub Pages 的站台。
- 場地可以接自己的筆電時，在筆電上用 static server 播放，不需要網路。
- 場地只能插隨身碟時，把簡報建置出來的目錄複製到現場的電腦，直接雙擊 `index.html` 播放，不需要網路，也不需要安裝任何軟體。

簡報由 AI agent 製作。框架提供版型元件、主題 token 與版面檢查指令，讓 AI 製作簡報時消耗的 LLM token 盡量少，同時做出版面正確的頁面。

## 目標使用者

經常對外演講與授課、會到陌生場地投影，並且用 AI agent 製作簡報的講者。目前只有專案擁有者本人使用。

## 範圍

播放器：

- 全螢幕播放。每頁在 1920×1080 的畫布上排版，播放時整個畫布等比縮放，所以在任何螢幕上的版面都和製作時相同。
- 頁內分步，也就是按一下才出現下一個項目。
- 換頁動畫與頁內元素的進場動畫：每頁在 TSX 檔裡用名稱從一組預設效果中挑選。
- Magic Move：換頁時，前後兩頁都有的元素從前一頁的位置與樣式移動到後一頁的位置與樣式，一般元素與程式碼都適用。
- 講者模式：在另一個視窗顯示目前頁、下一頁、講者備註與經過時間。
- 預覽總覽與拖曳排序。在本機開發時，新順序寫回簡報的設定檔；在其他環境，新順序與隱藏的頁面存在這台電腦的瀏覽器裡，可以還原成原本的順序。
- 亮色與暗色兩組配色，播放時可以切換。
- 用鍵盤、翻頁器與觸控滑動操作。
- 播放時用畫筆在頁面上標註。
- 匯出 PDF 講義。

框架：

- 每頁是一個 React 元件（TSX 檔），排版用框架的版型元件與 Tailwind CSS。
- 一套內建主題，顏色、字型、字級都定義成 token，個別簡報可以覆寫部分 token。頁面上的顏色只能使用主題 token。
- 支援的內容類型有圖片、簡報目錄裡的影片檔、程式碼、數學公式、Mermaid 圖、ECharts 圖表，以及可以操作的 React 元件。
- 建置時依簡報內容切出用到的字，把字型打包進建置產物。

AI 製作：

- 三個 skill：生成整份簡報與講者備註、修改頁面、把既有的 pptx 或 Markdown 轉成本框架的格式。
- 版面檢查指令：逐頁檢查超出畫布、文字溢出、元素重疊、字級過小等問題，並用文字回報。講者指定某一頁時，AI 才截圖檢查那一頁。

## 刻意不做的事

- 手機遙控：手機與播放的電腦之間需要一台轉發訊息的伺服器，不符合純靜態檔的前提。用翻頁器就能在離開電腦時換頁。
- 圖形化編輯器：簡報由 AI agent 寫成程式碼。
- 多人協作、雲端同步、帳號系統：用 git 同步與管理版本。
- 觀眾互動，例如即時投票與 Q&A：需要伺服器。
- 匯出成 pptx：與不依賴專用 app 的出發點相反。
- 嵌入 YouTube 等線上影片：沒有網路就無法播放，所以影片只支援放在簡報目錄裡的檔案。
