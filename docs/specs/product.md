## 定位

diapo 是一套純靜態網頁的簡報播放器與簡報框架。簡報的原始檔是程式碼，製作與播放都只需要瀏覽器，不依賴 Keynote、PowerPoint 這類專用 app，也不需要訂閱任何線上服務。同一份簡報 build 出來的目錄（在本產品中叫 slidetray）可以在三種場地播放：

- 場地有網路時，開啟部署在 GitHub Pages 的網站。
- 場地可以接自己的筆電時，在筆電上用 static server 播放，不需要網路。
- 場地只能插隨身碟時，把 slidetray 複製到現場的電腦，直接用瀏覽器開啟 `index.html` 播放，不需要網路，也不需要安裝任何軟體。

簡報由 AI agent 製作。框架提供版型元件、內建主題與版面檢查，目標是讓 AI 做出一份版面正確的簡報時，消耗的 LLM token 明顯少於使用 AI agent 內建的簡報生成功能，也明顯少於透過簡報軟體的 MCP server 製作。

## 目標使用者

經常對外演講與授課、會到陌生場地投影，並且用 AI agent 製作簡報的講者。目前只有專案擁有者本人使用。

## 範圍

播放器：

- 全螢幕播放。每頁在固定比例的畫布上排版，播放時整個畫布等比縮放，所以在任何螢幕上的版面都和製作時一致。
- 頁內分步，也就是按一下才出現下一個項目。
- 換頁動畫與頁內元素的進場動畫，從一組預設效果中挑選。
- Magic Move：換頁時，前後兩頁都有的元素從前一頁的位置與樣式移動到後一頁的位置與樣式，一般元素與程式碼都適用。
- 講者模式：在另一個視窗顯示目前頁、下一頁、講者備註與經過時間。
- 預覽總覽與拖曳排序。製作時調整的順序會存回簡報；在現場臨時調整的順序與隱藏的頁面只留在那台電腦上，可以還原。
- 亮色與暗色兩組配色，播放時可以切換。
- 用鍵盤、翻頁器與觸控滑動操作。
- 播放時用畫筆在頁面上標註。
- 匯出 PDF，每頁一張。

框架：

- 每頁是一個獨立的檔案，排版用框架提供的版型元件。
- 一套內建主題，個別簡報可以調整配色與字型。
- 支援的內容類型有圖片、影片、程式碼、數學公式、流程圖與架構圖、資料圖表，以及可以操作的互動元件。
- 字型和簡報打包在一起，跨平台、跨裝置顯示的字型都一致。

網站：

- 網站首頁以卡片列出所有發布的簡報，每張卡片顯示簡報第一頁的預覽，列表可以分頁。

AI 製作：

- AI agent 透過 diapo 提供的 skill，可以做到以下幾件事：
  - 生成整份簡報與講者備註。
  - 修改頁面。
  - 把既有的 pptx 或 Markdown 轉成本框架的格式。
- AI agent 做出頁面後，會自動檢查並修正超出畫布、文字溢出等版面問題。

## 刻意不做的事

- 手機遙控：手機與播放的電腦之間需要一台轉發訊息的伺服器，不符合純靜態檔的前提。用翻頁器就能在離開電腦時換頁。
- 圖形化編輯器：簡報由 AI agent 寫成程式碼。
- 多人協作、雲端同步、帳號系統：用 git 同步與管理版本。
- 觀眾互動，例如即時投票與 Q&A：需要伺服器。
- 匯出成 pptx：與不依賴專用 app 的出發點相反。
- 嵌入 YouTube 等線上影片：沒有網路就無法播放，所以影片只支援放在簡報目錄裡的檔案。
